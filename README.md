# 我的工具站

零基础第一个项目：纯 HTML + CSS + JavaScript 的单文件工具站，无需安装任何依赖。

## 功能

- 📏 单位换算（长度 / 重量 / 温度）
- 🔑 密码生成器（本地生成，不会上传到服务器）
- 📝 文本工具（字数统计、大小写转换）

## 使用

双击 `index.html`，用浏览器打开即可。

## 技术栈

- HTML5
- CSS3（CSS 变量、Flex、Grid、自动深色模式）
- 原生 JavaScript（DOM 操作、事件监听、Clipboard API）

## 在线访问

开启 GitHub Pages 后访问：

```
https://<你的用户名>.github.io/<仓库名>/
```
